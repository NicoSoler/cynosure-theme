# Cynosure

VS Code colour themes modelled on the Cynosure terminals from Cyberpunk 2077's
*Somewhat Damaged*, part of the Cynosure desktop theme (GTK, GNOME Shell, Sway).

- **Cynosure Breach**: the breach-protocol screens. Near-black navy, cream text
  and rules, the title bar as a cream header strip.
- **Cynosure Parchment**: the "CONTROL PANEL" terminals. Aged paper, ink text,
  navy title, activity and status bars.

Syntax colours match the terminal palettes used by the foot config, so the
editor and the terminal agree.

To follow the system light/dark setting:

```json
"window.autoDetectColorScheme": true,
"workbench.preferredDarkColorTheme": "Cynosure Breach",
"workbench.preferredLightColorTheme": "Cynosure Parchment"
```
